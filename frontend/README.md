# VTU Site Frontend

This is the frontend for the VTU Site, built with React and Vite.

## Tech Stack

- **React 19** & **Vite**: Core framework and bundler.
- **Styling**: TailwindCSS.
- **Routing**: React Router DOM.
- **State Management & Data Fetching**: React Query (`@tanstack/react-query`) and Axios.
- **Forms**: React Hook Form.
- **Icons**: Lucide React.
- **Linting**: Oxlint.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
